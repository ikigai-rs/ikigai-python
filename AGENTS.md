# AGENTS.md

`ikigai-python` is a Python client and servable peer for the ikigai wire protocol.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Run `scripts/gates.sh` (what CI runs) before opening a pull request.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-python/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
