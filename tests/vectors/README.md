`contract_cases.json`, `contract_vectors.json`, `failure_class_cases.json` and
`failure_class_vectors.json` are verbatim copies from
[ikigai-core revision dc6d0ac6c48d9c31b0059609c564705627853bf5](https://github.com/ikigai-rs/ikigai-core/commit/dc6d0ac6c48d9c31b0059609c564705627853bf5).
They include the body-reader and resend contracts, the `core/resend` Turtle door,
and the gave-up failures and JSON faces from core 0.3.4/0.3.5.
Copy these files without reformatting; `.gitattributes` keeps their line endings LF.

A declared `resend` selects contract v2 and appends byte 5 after the fixed-input
tail, followed by byte 0 for `"safe"`, or byte 1 and the length-prefixed key name
for `{"key": name}`. Absent or null feeds nothing and declares no resend safety.
Never infer resend safety from the verb. The upstream vectors README documents
all canonical digest tails. Gave-up elapsed time is rounded down to milliseconds;
retry-after delays are rounded up.

The supplemental
`fixed_contract_vectors.json` pins named request metadata against
[ikigai-core revision 65ed423e4b1cdef7951580b36d18ceb1a9157f4d](https://github.com/ikigai-rs/ikigai-core/commit/65ed423e4b1cdef7951580b36d18ceb1a9157f4d).
That revision implements the fixed tail but has no shared fixed-input vector cases yet.
The supplemental expectations were generated by Rust, not the Python implementation.

To reproduce these expectations using that core revision:

1. Append the supplemental `contracts` rows (omit each output `contract`) and `doors`
   rows (omit each output `turtle` and `actions`) to the corresponding arrays in
   `crates/ikigai-vocab/tests/vectors/contract_cases.json`.
2. Run `cargo test -p ikigai-vocab --test contract_vectors -- --ignored` in core.
3. Compare the generated `v2/fixed-*` rows in core's `contract_vectors.json` with the
   supplemental fixture's rows. Keep the generated contract IRIs and Turtle verbatim.

Cases cover one fixed input, two fixed inputs, the reversed declaration order, and an
empty fixed value. A fifth case combines the fixed tail with stated failures and
existence sensitivity, and exercises Turtle predicate ordering and literal escaping. `tests/test_fixed_contract.py` consumes every row and also asserts
unchanged existing v1/v2 digests and deduplication. Once these cases enter the shared
upstream vectors, they can move into the regular verbatim copy carried by vector-drift.
