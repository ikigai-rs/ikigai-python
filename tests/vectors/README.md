The supplemental expectations were generated by Rust, not the Python implementation.

To reproduce these expectations using that core revision:

1. Append the supplemental `contracts` rows (omit each output `contract`) and `doors`
   rows (omit each output `turtle` and `actions`) to the corresponding arrays in
   `crates/ikigai-vocab/tests/vectors/contract_cases.json`.
2. Run `cargo test -p ikigai-vocab --test contract_vectors -- --ignored` in core.
3. Compare the generated `v2/fixed-*` rows in core's `contract_vectors.json` with the
   supplemental fixture's rows. Keep the generated contract IRIs and Turtle verbatim.

upstream vectors, they can move into the regular verbatim copy carried by vector-drift.
